JavaScript Hands-on

classList で
動くUIをつくろう

見た目（CSS）はもう用意してあります。
JavaScript でやるのは「クラスを付ける・外す」だけ。

TASK 01 ★☆☆

ハンバーガーメニュー

右上の ≡ ボタン を押したらメニューが開き、× ボタン を押したら閉じるようにしよう。

  • ≡ を押す → .drawer に is-open を追加
  • × を押す → .drawer から is-open を削除

TASK 02 ★★☆

モーダルウィンドウ

ボタンを押したらモーダルが開き、× ボタン か 背景（黒い部分） をクリックしたら閉じるようにしよう。

  • 開く → .modal に is-open を追加
  • 閉じる → .modal から is-open を削除（2か所から）

TASK 03 ★★☆

スクロール連動ヘッダー＆ページトップボタン

ページを 100px以上 スクロールしたら、ヘッダーの見た目を変えて、右下に「↑」ボタンを表示しよう。

  • 100pxより下 → .header に is-scrolled、.pagetop に is-show を追加
  • 100px以内に戻る → 両方とも削除

TASK 04 ★★★

タブ切り替え

タブをクリックしたら、そのタブと対応するパネルだけが表示されるようにしよう。

  • タブの data-target には、表示したいパネルの id が書いてあります
  • 今 is-active が付いているタブとパネルを探して、is-active を削除
  • クリックしたタブと、data-target のIDのパネルに is-active を追加

HTML ＝ 骨組み

ページに「何があるか」を決めます。見出し、文章、ボタン、画像など。

CSS ＝ 見た目

「どう見えるか」を決めます。クラスごとに見た目のルールを書いておきます。

JavaScript ＝ 動き

「いつ・どのクラスを付けるか」を決めます。今日の主役です。

TASK 05 ★★★ 発展

画像ギャラリー（複数のモーダル）

サムネイルをクリックしたら、その画像の大きいサイズがモーダル（ライトボックス）で表示されるようにしよう。× ボタンか背景を押したら閉じます。

  • サムネイルには data-full（大きい画像のURL）と data-title（タイトル）が付いています
  • 開く → ライトボックスの画像にURLを入れて、.lightbox に is-open を追加
  • 閉じる → data-action="close" が付いた要素を押したときだけ is-open を削除
